## English

Title: Jev Decision Gate: triage Issues, keep uncertainty visible

Description: A free open-source Python, MCP and Skill tool. Start with local rules, optionally call Jev, and evaluate acceptance on independently labeled cases.

Body: Turn issue titles and descriptions into suggested kind, module and information-sufficiency labels. Uncalibrated, incomplete or failed judgments stay in review. The tool does not edit labels, post comments or close issues.

Primary action: Read the GitHub installation guide.

Secondary action: Run 12 local synthetic examples.

Evidence note: The offline demo does not call Jev and is not a customer result. The Jev adapter is implemented; measure quality and cost with your own account and workload.

Commercial note: The local tool is free and open source. TypeSafe usage is billed separately. No hosted Decision Gate service is currently offered.
