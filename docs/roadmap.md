# Roadmap and release boundaries

Current: installable Python preview, CLI, local MCP, Skill, rules baseline, Jev HTTP adapter, independent calibration/evaluation, one synthetic developer case, bilingual instructions. MIT core.

Next evidence: live TypeSafe contract verification using the owner's local credential; independently labeled real Issue data with permission to use it; comparison to rules and the team's existing workflow. No fixed savings promise or claimed customer count.

Distribution: independent public `f-tiger/jev-decision-gate` repository; useful README example; link to existing BPJ developer page. Repository creation/publication, package registries, MCP Registry and website deployment are distinct stages. Do not use badges implying a stage has completed before it has.

Commercial hypothesis: maintainers use the free local tool; teams with repeated workloads might buy hosted regression evaluation, policy history and human-reviewed calibration. There is no paid Decision Gate checkout in this version. Do not assume an existing BPJ subscription includes it.

Reassess after 28 days of actual distribution: five independent developer installs, two returning teams with labeled reports, one recurring-service request. These are proposed decision criteria. Installs, successful runs, retained users, inquiries and payments are separate evidence; Star/Fork counts alone are insufficient.

Later, only if this first case is useful: CI log reduction with a deterministic-filter ablation; Skill/MCP tool selection with measured routing accuracy and host integration. Avoid a generic “saves tokens everywhere” wrapper.
